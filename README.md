# zopguard —— ZopToken 掉线自愈守护

每 3 分钟由 launchd 自动运行，ZopToken 客户端掉线时全自动恢复，全程飞书通知。**本仓库只含通用脚本，无任何凭证。**

## 能力
- **进程掉线/假活** → 自动退出重开（客户端静默重连）
- **登录态掉线**（登出/槽位到期）→ API 直登恢复槽位，零 GUI 零权限
- **飞书通知**：掉线 ⚠️ / 恢复 ✅ / 部署 🟢，全程不用盯
- **自更新**（v1.6）：发布新版本后，已部署的机器 3 分钟内自动升级

## 安装
一条命令（含飞书 webhook / 应用凭证、ZopToken 登录密钥，按安装包说明填写）。

## 自更新机制
- 机器上 `config.sh` 配 `AUTO_UPDATE_URL` 指向本仓库 `guard.sh`（jsdelivr CDN）
- 每轮顺带查 `VERSION`，不一致则下载 → shebang/语法/版本号三重校验 → 替换 → 重启守护
- 下载失败/校验不过 → 保持旧版，下轮再试（绝不安装损坏文件）
